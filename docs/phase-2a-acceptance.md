全为人工合成算法数据，不代表真实行情或盈利能力。本轮没有UI入口；使用 `npm ci`、`npm run check` 及 `npx vitest run tests/unit/backtest.test.ts`。Python可选：`python3 tests/reference/backtest-reference.py`，输出应与固定JSON三项buy/sell/totalFees相同；CI不靠被测实现生成参考。
