# Phase 5D Windows 验收单

在 Chrome 和 Edge 的独立配置各执行一遍。记录版本、完整提交、实际操作、观察值和 PASS / FAIL / BLOCKED / NOT TESTED。测试包身份来自 Phase 5D Draft PR。用户 5D Windows 实机和物理断网当前均为 NOT TESTED。

| 项目       | 操作与核对                                                                                                                                                  |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 包与启停   | 核对内层 ZIP 的 SHA-256、build-info 完整提交、版本 1.2.0-test.1 与 dirty=false。解压至中文空格路径，使用 Node 24 和 BAT 启动本机 HTTP，结束时确认端口释放。 |
| 原功能     | 导入 RC 原实验、5C-A 固定子账户、5C-B 共享策略与再平衡 JSON。在各自入口验证重算成功、原 Hash、成交、费用和终值。                                            |
| 状态与边界 | 在市场状态研究入口选已存实验。记录 N、基点阈值、源实验身份。检查前 N 个收盘 UNKNOWN、上涨/下跌等号归震荡、末根标签生效时点；缩窄窗口并切换深浅主题。        |
| 连续区间   | 对照 UTC 开始、结束、出现次数与切换次数。检查同一期间可查询参考 K 线和上一收盘已知标签。逐段核对真实起止权益与绝对变化。                                    |
| 贡献与费用 | 对照原报告，加总四类净盈亏、成交、手续费；检查含跨状态持仓的已实现/浮动变化、暴露和各类占时。记录原值及差额。                                               |
| 组合参考   | 分别选择固定、共享策略、再平衡。先保留参考为空再显选不同资产；观察标签变化，并核实组合本身的净盈亏、费用和成交总数。                                        |
| 备份       | 保存、刷新重开、导出 JSON 和 CSV。全新配置只导入 5D JSON，核对报告 Hash、参考资产、参数、所有区间与汇总；再保存与重开。                                     |
| 异常与取消 | 试无效 UTF-8/JSON、未知版本、Hash 篡改、ID 冲突、存储失败、运行中取消。核对原保存报告并重试。删除分别测试放弃和确认。                                       |
| 容量       | 单币种 50,000 根、组合合计 10,000 根。记录运行/导出/恢复毫秒、主线程最大间隔、JSON 字节数、可用内存观测以及失败与重测。                                     |
| 物理断网   | NOT TESTED。实测后记录操作、浏览器和结果。                                                                                                                  |
