# Phase 3 策略研究设计

用户于2026-11-09明确授权“启动 Phase 3 设计与开发”。基于 PR #6 实际合并33b1d669；本轮独立分支、Draft PR #7，绝不直接修改main、自动合并、Release或公开部署。此前Windows用户实机验收仍待反馈。

## 目标与边界

实现原始规划Phase3：多策略批次比较、参数敏感度热力图、收益/回撤比较、样本内外按时间拆分、滚动测试和过拟合警告。React只配置和展示；core/research纯TS编排原runBacktest/calculateStatistics；专用Worker隔离计算。既有策略版本、18位BigInt、成交时序、保护优先、双触发stop-first、费用/滑点和末尾不清仓均不改变。全量保留原回归。

比较模式使用公开固定MA2/5、RSI3/30/70、突破3；网格模式允许MA快/慢、RSI下/上阈值（固定周期）或突破单轴回看。网格先整体验证，禁止自动去重、跳过无效单元或自动修复数据。不增加自动优化器、自动“最佳策略”、AI、实盘或网络数据。

## 时间与研究口径

输入完整dataset-v1先验证全部数据（包括滚动未评估尾部）；未确认、缺口、非法、重复、未收盘、定点精度无效均阻断整批。UI只能选择保存的数据，确认全部收盘；核心要求显式收盘边界，UI另外检查当前系统时间。保留来源、周期、警告及原文件身份。

区间采用原始数组下标半开区间[start,end)，结果显示真实UTC首开盘/末收盘。显式派生连续窗口不是修复原数据；派生质量的行数/范围代表窗口，原文件SHA、来源和导入警告仍指向原导入。报告保存完整原dataset，窗口下标、窗口数据hash、信号hash和运行hash，原dataset不写回。

全区间用于描述；split为[0,trainBars)、[trainBars,N)。rolling固定长度训练窗向前移动testBars，后接同样长度测试窗。测试不重叠；训练可重叠，后折训练可包含较早已过去的测试数据，但从不包含本折未来测试。尾部不足完整测试窗时不评估，结果明确数量，原数据仍完整校验并保留。不提供静默截断或跨缺口子集。

每窗独立重置同一本金、空仓、指标冷启动；不跨边界继承信号、持仓或预热。信号仅在当前完成K线上生成、下一开盘成交；窗口末尾无下一根的信号按原规则到期。MA至少慢线+1、RSI周期+1、突破回看+1根才能形成首个有效判定，还需下一根才能成交；不足明确警告、完成交易指标NA，不把空仓零收益解读为有效策略。

所有候选在开始前锁定并全部运行于训练和测试。不自动按训练或测试收益选优，不把单一收益指标称为“最佳”。UI切换窗口同时展示收益、最大回撤、完成交易、胜率、利润因子、买入持有和年化；热力图格内同时显示收益与回撤，可点击查账本。不同独立窗口绝不拼接/复利/声称连续投资收益。仅有限网格描述，没有显著性检验或参数寻优保证。

## 成本与统计

统一初始本金默认1000USDT、双边费10bps、买/卖不利滑点各10bps、数量8位、最小名义额0，可显式修改；保护留空关闭。资金/费用/绝对金额仍固定18位BigInt，不用Number累计金额。沿用statistics-v1全部定义：净盈亏=末收盘权益−本金，现金/持仓市值/权益分明，已实现+浮动=净盈亏。仅完整空仓至再空仓周期用于胜率/利润因子，含手续费与成交价滑点；无交易、无亏损分母、短样本年化按原NA原因处理。年化仅>=365天且>=252根、首末权益正。比例向零截断12位；UI百分比近似显示2位，原始精度在报告。

基准每窗首开盘、同本金、同买成本/数量精度/最小额，无保护，末收盘估值不清仓，不扣卖成本。回撤按每根收盘、含初始锚点；暴露是根内时间未知时的上界。不把未平仓浮动计成已完成胜负。绝对金额在结果/报告保持原规范字符串。

## 性能、复现与存储

候选最多25、滚动最多20折、总子运行最多100、总K线求值最多1,000,000；超限明确拒绝，不静默抽样。Worker逐个子运行，及时释放全量成交/曲线，仅返回对比摘要/终值/哈希；数据快照只保存一次，原单次回测仍保留全量逐笔/曲线和实验保存功能。研究工作台可以取消整批，终止Worker，不显示部分成功报告。

研究结果只在当前app内存，跨页面保留；配置组件离开页面后重置，刷新清除报告和配置。原保存数据/回测实验仍为IndexedDB明确保存契约，不被研究功能覆盖。JSON包含完整输入快照、锁定参数/成本/风险/时间窗口、版本、假设、指标定义、结果和payloadHash；导入上限25MiB，先校验hash再在Worker全部重算逐项比对，不写入dataset库。只支持当前研究算法版本；损坏/旧版本拒绝。CSV为所有候选/窗口对比摘要，NA有原因列；详细交易仍在单次回测导出。所有报告含“仅供学习研究，历史表现不代表未来表现”。Hash保证确定性，不能认证原行情真伪或防恶意伪造。

50,000根实际三策略批次性能记录CPU、核数、OS、Node、浏览器、墙钟与主线程20ms定时器延迟；上限20秒、主线程最大1000ms，沿用已有单回测阈值，不放宽或删除断言。100万求值是资源预算，非所有硬件速度承诺。
