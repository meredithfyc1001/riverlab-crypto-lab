# Phase 5D 市场状态识别与策略表现归因设计

PR #13 合并提交为 `06635d3dc385b4645b21cfbda1edd68f23e3de89`。本阶段在独立分支 `feat/phase-5d-market-regime` 开发，测试版为 `1.2.0-test.1`。研究的对象是已保存且能够按原版本重算的现货历史实验。市场状态仅描述模型看到的行情，无法确定客观市场周期或预测未来。

## 判定与生效时刻

观察周期 N 为 1 至 50,000 的整数，趋势阈值 T 为 1 至 10,000 的整数基点。默认 N=20、T=500（5%）。运行使用一次性参数快照。设 C 为当前已完成收盘价，P 为同一连续序列 N 根之前的收盘价。使用 Phase 2A 规范十进制转 18 位定点价格，比较 `(C−P)×10000` 与 `±P×T`。严格大于上界为 BULL，严格小于下界为 BEAR，含等号的中间范围为 SIDEWAYS。小于 N+1 个收盘返回 UNKNOWN。判定前不做比率除法或显示舍入。

第 i 根收盘已知的标签最早影响第 i+1 根的归因。每根的 UTC 期间从开盘到下一周期开盘，右端点排除。首根归 UNKNOWN。末收盘产生的标签仍可查看，尚无下一期间可归因。图表和区间统计使用生效标签。拒绝缺口、重复、乱序、未收盘及组合时轴错位。组合由用户明确选一项作为参考，在原实验共同区间重新预热。

## 连续账户与守恒

采用原实验初始本金作为锚点，第 i 根对净盈亏的贡献为本根收盘权益减上一个权益锚点。将该差额和本根已成交订单数、实际手续费归入该根的生效标签。卖出时按数量向下分配历史含费成本，最后一次退出承担余数。分资产保留跨标签的成本基础。已实现的变化加浮动盈亏的变化逐根等于权益变化。所有金额均按 18 位 BigInt 最小单位核算。四类贡献之和须与原实验净盈亏逐单位相等。按根检查权益和成交，避免在每次状态变化时虚拟平仓或重复扣费。

持仓暴露沿用原统计上界。开盘清仓后持续空仓的期间计零，根内保护退出计整根。组合内只要任一资产暴露便计一个期间。时间占比以各类归因期间的时长除以共同总时长。出现次数按连续生效区间计，切换次数按相邻期间标签变化计。每段收益以该段真实起止权益计；零分母记 NA。基础资产与权益分别描述逐期间简单收益的分布，波动使用非年化的逐期间标准差。区间收益率不相加。

## 复现与资源

单币种、固定子账户、策略共享池和定期再平衡均先经过原验证器。独立 5D V1 报告保存原实验身份、算法版本、原始数据来源和 Hash、完整复现输入、用户显选的参考资产、研究参数、每根收盘标签、区间和各状态汇总。报告 Hash 为规范 JSON 中除自身外全部字段的 SHA-256。导入和重开时从内嵌输入恢复原实验、核对身份，然后重算研究及完整报告 Hash。该过程无需本地数据或策略库。

专用 Worker 负责加载源实验、验证、计算和文件编解码。每个任务独立，取消时终止 Worker，过期结果不得进入界面。用户显式保存后，在独立 IndexedDB 的同一事务新增正文与摘要；同 ID 拒绝覆盖。单币种原始上限 50,000 根，组合所有源快照合计 10,000 根。研究报告采用 32 MiB 的文件和规范编码预算。报告树使用既有 256 MiB 逻辑准入模型，计入解码和双树核对，原回测引擎另有自身账本分配；浏览器进程 RSS 要通过实测观察。JSON 用于恢复，CSV 用于交换汇总和连续区间。
