# 回测约束（Phase 2B）

纯 TypeScript 内核支持MA交叉、Wilder RSI阈值、价格突破，以及独立固定测试信号入口；2C通过Worker接入回测UI。默认1000虚拟USDT、现货/多头/单币种/无杠杆。所有K线已完成，收盘信号仅下一根开盘执行，无下一根则到期，无自动末尾清仓。正式策略只接收已完成单根，不接收未来数据。

18位BigInt账本、双边费用/滑点、数量向下、资金不足拒单及累计对账延续2A。无限流动性/忽略整根量/无订单簿/无冲击是假设，不能视为实际可成交；滑点不按high/low裁剪。Number来源精度不可恢复；缺口/异常/未完成/定点越界数据阻断，不补价或修复。

保护基于实际滑点买价、不含手续费。已有仓位开盘触发保护优先并取消待执行信号；否则先执行信号，再检查新仓是否已可在open触发，最后处理未知根内路径。止损跳空按open，止盈跳空保守按take放弃改善；保护是触发市价，仍扣卖滑点/手续费，不是限价成交保证。双触发明确假定stop-first，根内时间记null和区间，不编造路径或时间。部分卖后保护余仓，无同根重复清仓/再买。

manifest保存算法/转换版本、数据/实际信号/运行SHA-256、策略类型/版本/参数、风险/成本配置、来源和全部假设。相同输入JSON完全一致；追加未来不改变已完成历史结果，全量hash和末根到期状态可随追加变化。固定信号仍不认证外部作者的因果性；截止时间由调用者声明。

详见 [2B设计](phase-2b-design.md)、[自查](phase-2b-review.md)和[Windows验收](phase-2b-acceptance.md)。[2A设计](phase-2a-design.md)保留原规格。RSI指标仍为IEEE754，接近阈值有舍入边界。2C增加收益/公平基准/回撤/统计NA/实验存储和JSON/CSV，口径见[2C设计](phase-2c-design.md)；参数优化/AI/实盘均未实施，不代表整个M2完成。
