# 回测约束（Phase 2A）

2A 提供纯 TypeScript 计算内核，只有人工固定信号，无 UI 回测入口或正式策略。默认1000虚拟USDT，仅现货/多头/单币种/无杠杆。全部K线须已完成，收盘信号仅下一根开盘模拟成交，无下一根则到期；不自动末尾平仓。

成交不是盘口成交：假定无限可用流动性、全额成交，忽略包括零量在内的整根成交量（开盘时尚未知）。买卖分别使用开盘价加/减配置滑点，不以当根高低价裁剪。手续费以已舍入名义额的报价币双边扣取；资金不足或持仓不足拒单，不允许负数。

18位BigInt定点账本，买价/买名义额/费用向上、卖价/卖名义额/估值向下、数量向下按配置精度对齐。逐笔检查守恒并保存余额、仓位、权益变化。Phase1 Number价格转最短十进制字符串，不声称恢复原CSV精度；无法精确转换或超出范围阻断。数据缺口、未完成根、质量不合格均阻断。

结果携带算法/转换版本、数据/固定信号/运行SHA-256、原文件哈希、参数、成本及假设。计算不读系统时钟，外部运行时间应另行记录。来源与首尾完整性仍不能认证。固定信号不保证其作者因果性，2B须另验正式策略。

完整成交/精度/身份规则见 [Phase 2A设计](phase-2a-design.md)，固定案例见 [验收清单](phase-2a-acceptance.md)。止盈止损、同根双触发/跳空退出、基准/收益/回撤/NA、实验持久化及可视化仍未实现；2A不代表整个M2完成。
