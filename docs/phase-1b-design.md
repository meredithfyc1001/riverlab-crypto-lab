# Phase 1B：图表、指标和本地数据集

## 选型与模块

2026-10-19 从 npm 核对 Lightweight Charts **5.2.1**（包修改时间 2026-08-12），Apache-2.0。选择理由：Canvas 渲染、内建缩放/平移/十字准星、原生多面板和 TypeScript 接口，适合当前最多 50,000 根的浏览器历史数据。源码经 npm 固定版本本地打包，没有 CDN、遥测、远程字体或行情请求。保留 TradingView attributionLogo、页面作者/链接及随包 LICENSE/NOTICE（public/licenses/lightweight-charts）。这不是对未来维护状态的保证。

- `core/data` 保留 1A 解析/质量接口；新增 dataset-v1 纯数据契约和边界验证。
- `core/indicators` 纯 TS，独立无 DOM 编译，只计算收盘价 MA/EMA/RSI。
- `features/datasets` 保留报告 Worker 消息；用户明确操作后，Worker 以同一文件 SHA-256 和解析约定重新检查，再返回完整候选数据。错误/待确认/空数据一律阻断，不截取有效子集。
- `app` 负责数据中心、行情中心及存储服务装配；兄弟 features 不直接相互导入。
- `infrastructure/dataset-store` 原生 IndexedDB 事务及 JSON 备份适配器，不进入 core。不增加存储封装依赖，测试用 fake-indexeddb 6.2.6，浏览器测试实际使用 IndexedDB。
- 策略、回测、风险等边界不增加执行功能。

## 图表与数值口径

内部始终 UTC 整毫秒；只在图表适配器使用 `ms / 1000` 的 UTCTimestamp，读数按 `round(seconds * 1000)` 恢复 UTC，支持毫秒精度。与用户本地时区无关，不生成日历字符串作为行情身份。价格读数对极小/极大数采用科学计数法，避免小正数显示为零；图表价格刻度按数据量级设置，超出可靠刻度范围明确失败，不修改原始数值。展示会格式化，JSON 保留原始 JS number，不代表十进制账本精度。

K 线和成交量在主区域，MA/EMA 叠加；RSI 在独立面板共用时间轴。滚轮/拖动和按钮支持缩放、平移、恢复全图。十字准星读取对应 OHLCV、UTC 和主图指针价格，指标显示该根的值；指针离开回到末根。深浅主题切换重建图表并保留视区；卸载移除 Canvas、订阅和未完成绘图任务。

时间轴按观测数据压缩长缺口，每处最多一个额外空白位置，不分配 missingCandles 个假 K 线。页面持续显示原始缺口/缺失数量；指标遇到缺口重新预热，不跨缺口计算。缺口不是自动修复，也不能据此推断停牌或采集缺失原因。

## 指标定义与独立参考

周期 N 是 1–50,000 整数，非法/空周期明确报错并停止图表，不能沿用旧值。

- **MA / SMA**：最近 N 根收盘价算术平均，第一值位于索引 N−1。以均值计算减少有限大数求和溢出。
- **EMA**：前 N 根的 SMA 为第一值（索引 N−1），之后 `EMA += (close − EMA) × 2/(N+1)`；不从第一根伪造完整 EMA。
- **RSI**：首 N 个收盘价差的上涨/下跌算术均值初始化（第一 RSI 在索引 N，需要 N+1 根）；此后 `avg = avg × (N−1)/N + change/N`（Wilder，α=1/N）。双零定义50，纯涨100，纯跌0；其余 `100/(1+avgLoss/avgGain)`。
- 每一值只访问当前/历史；缺口后将起点、均值、EMA、RSI 状态全部重置，预热不足 `null`，UI 为 NA，不补值。指标不是策略信号。

固定 fixture `tests/fixtures/indicator-reference.json` 为算法数值样本，不称为行情。独立 Python Decimal 60 位闭式加权和脚本 `tests/reference/generate-indicators.py` 为各时间点重新计算参考，避免镜像 TS 递推实现。33 个固定价格、N=14，逐点比较 MA/EMA/RSI；Wilder 首个 RSI=70.46413502109705。Python 仅用于可选重建参考，不是应用/CI 依赖。另验证前缀不受未来变化影响、常量/单向/N=1、缺口、非法/不足/大数等。

## 保存边界与来源

只有 status=reviewed、零错误/零无效行/零待确认、非空且完整保留所有文件记录的数据可以用于图表或保存。所有原警告、空白行统计、文件内范围与不完整性说明保留；有错误的原文件不能通过“只存好行”绕过。来源自述不认证行情，合成/真实存档/错误样本标签沿用 1A。

显式填写币种、阅读质量报告并勾选警告确认后才启用使用/保存。保存 dataset-v1 包含 UUID、名称、币种、创建时间、来源类型/说明/上游链接、文件名/字节数/SHA-256、csv-v1、列映射/分隔符/表头/原时间单位/用户周期、UTC OHLCV、质量警告/范围/缺口/统计与确认状态。**不保存原始 CSV**，不承诺以备份重建其逐字节原文；文件 SHA 仅追踪原输入身份。

## IndexedDB 与故障

数据库 `riverlab-crypto-lab` v1，有 datasets 与 summaries 两个 store。同一 readwrite 事务原子写入/删除，**仅 oncomplete 才返回成功**；request success 后 abort 仍失败，异常尝试 abort。列表只读摘要，不把所有行情加载进内存；打开时重新验证完整数据，摘要损坏也拒绝使用。关闭连接、versionchange 释放；升级被其他页阻塞/打开5秒超时给出失败。

不会退化成假保存或自动丢弃数据。QuotaExceededError、SecurityError/NotAllowedError、中止、阻塞、损坏、未知错误均显示失败。失败后当前导入数据保留在内存，可单独导出；删除失败保留列表及已打开数据。跨标签页没有实时同步：其他页删除后打开会报不存在，刷新可重读列表。

浏览器存储限于当前协议/主机/端口和用户配置，不跨 Edge/Chrome 自动共享。隐私模式、策略、空间回收、清除站点数据可能使其不可用或消失；没有申请永久存储权限，也不能称为永久可靠存储。成功事务不是断电级耐久保证。

## 备份与恢复

明确导出当前内存数据为 JSON（无错误子集），包含 format=riverlab-dataset、version=1、完整 dataset 和 payload JSON 的 SHA-256。备份校验和检测损坏，不认证来源，第三方可重算。恢复验证 UTF-8、JSON、版本、校验和、字段、OHLC、UTC 整毫秒、严格递增、周期、行数、缺口/范围及质量一致性；再展示来源/范围/警告并要求确认，恢复为新 UUID 副本，不覆盖旧数据。恢复同样遵守 50,000 根和原 CSV 身份 10 MiB 限制。

JSON 比 CSV 多字段名和元信息，单份备份另设 **20 MiB** 字节上限（读取前及解码后检查），不是提高 CSV 导入上限；CSV 仍 10 MiB / 50,000 行 / 64 列。JSON 是规范化数据备份，原 CSV 可走原 1A 映射流程重新导入。未知 schema/parser 版本拒绝，未来迁移需另行实现。

## 性能与离线边界

维持 1A 上限。解析/哈希继续 Worker，可取消且旧响应失效；完整数组仅在明确使用/保存时传递。当前选中数据和最多一个待恢复预览在内存，不加载全部已保存数据集。指标 O(n)；图表不降采样、不截断 K 线，每个序列间让出事件循环，取消后不再继续构建。十字准星二分查找并按帧调度，不重复线性扫描。绘图仍在主线程，单序列 setData、JSON stringify/parse 和结构化克隆仍可能短暂阻塞；不是流式或无限数据方案。

测试固定 50,000 根**人工合成**数据，输出字节数、检查/保存/重开图表/缩放/备份耗时与10ms定时器最大间隔到 CI artifact。此时间含自动化调度，受机器负载影响；5秒响应/15秒重开为 CI 宽松健全性门限，不是产品性能承诺。实际测量记录 progress。

生产包所有功能从本机 HTTP 加载，阻断其他 origin 后验证导入→保存→重开→图表→备份→恢复。没有外网抓取；没有验证 file://、PWA、离线安装器或首次离线 npm 安装。本轮不发布、不部署、不涉及真实账户/API Key/资金/交易。
