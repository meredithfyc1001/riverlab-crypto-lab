累计容量样本的正式导出及文件回读共 60.772 秒。包含构建测试页、创建样本和进程启动的生成命令耗时 89.900 秒，进程树最大观测 RSS 为 1,331.1 MiB。迁移进程树有 2,616 个 RSS 样本，各次采样间隔包括 100 ms 等待与系统进程枚举开销。RSS 求和可能重复计算共享页，也可能错过短时峰值。各阶段独立计时，外层墙钟还包含进程启动、最终输出等开销。Windows 原生性能为 **BLOCKED**。[原始指标](phase-6c-b-performance.json)

**事务中途失败和重试。** 写入第一条记录后在隔离候选连接中再次插入同一物理主键，实际错误为 `UNIQUE constraint failed: records.kind, records.id`。事务滚回耗时 0.075 ms，失败前后快照 SHA 相同，正式库未打开。相同输入在新目录重试后取得 READY。重复导出的小包具有相同内容指纹和 SQLite SHA，源文件各自保留独立 SHA。[故障及重试回执](phase-6c-b-performance.json)

**格式边界。** 整包按流式文件输出，256 MiB 限制作用于单条正文投影。独立编码边界样本精确生成 268,435,456 字节正文，外部 SHA-256 已核对，额外一个字节触发容量错误。深度 64 成功编码，深度 65 被拒绝。边界对象仅检验格式，不计入健康迁移或 READY 统计。此测量命令耗时 9.223 秒，82 次进程树采样的最大 RSS 为 636.8 MiB。[边界程序](../scripts/profile-snapshot-codec.mjs)

## 在隔离环境复测

在源码根目录执行 `npm ci`，准备 Node 24、Python 3 和 Playwright Chromium。可通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 明确指定系统 Chromium。命令接受隔离测试快照及其外部 SHA，输出目录必须是新目录。Linux 和 macOS 使用 `ps` 获取进程树，Windows 使用 PowerShell 读取进程工作集。

```sh
python scripts/phase6c/profile_migration.py --snapshot SYNTHETIC.riverlab-migration --sha256 EXTERNAL_SHA256 --output-dir work/new-migration-profile
```

每个场景保存运行日志、候选或失败回执和性能 JSON。新运行同时生成逐次 RSS CSV，已用小包及回滚场景独立核对 CSV 最大值与回执一致。可用 `--profiles near-capacity --generated-dir work/new-migration-profile` 在另一新输出目录复用已生成、带回执的合成容量快照。浏览器导出始终启动测试进程和临时上下文。[测量程序](../scripts/phase6c/profile_migration.py)
