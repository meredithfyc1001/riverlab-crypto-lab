## 功能（严格限制为单币种、现货多头、无杠杆、历史模拟）

1. 新增严格类型、**纯 TypeScript 的声明式 StrategyRuleV1 / DSL**，JSON 可序列化，无任意 JS、eval、Function、动态代码、外部脚本、网络请求。
2. 可视化编辑器：为买入、卖出分别配置规则组，每组支持有限条件（首版每组至多 5 条），支持 AND / OR 组合，顺序清晰，可添加、编辑、删除、启用/禁用、复制，并实时校验与中文解释。优先规则卡片/表单而非高维护的拖拽画布；保留深浅主题、390px 适配、键盘可访问性。
3. 条件库先复用现有指标/语义：MA/EMA 交叉或价格与均线比较、RSI 阈值（含等号界定）、前 N 根 high/low 突破（当前根不参与窗口）。支持用户调整合法周期、阈值，禁止无限嵌套、非法组合或隐藏类型转换。若某条件实现与既有策略语义不同，明确在设计、UI 解释和测试中标注。
4. 只向策略核心逐根传入**已完成 K 线**；缺少 warm-up 时标记不可判定，不将其当 false 生成意外触发；禁止使用未来价格、未来最高/最低、完整数据数组或未来索引。对持仓侧动作、同根买卖同时满足、同一信号重复触发、规则优先级设定明确且保守的确定性规则（建议冲突时 hold 并标注原因）。
5. 将规则策略接入现有 runBacktest 及 Phase 2C 回测 UI，**原 MA/RSI/突破三策略完全保持既有输出、版本与哈希语义**；扩展策略联合类型时采用明确的新规则版本，包含规则规范化配置、版本与数据哈希，支持精确复现；不要重写 18 位 BigInt 成交账本、手续费、滑点、止盈止损与统计口径。
6. 自定义规则支持保存、复制、修改产生新版本、删除确认，JSON 导出/导入并严格校验和拒绝坏版本/坏字段；本地 IndexedDB 不保证永久保存。保证旧实验/研究/回放/Monte Carlo 报告仍能打开复现，旧 schema 不做破坏性覆盖。
7. 第一版如不能保证与 Phase 3 网格/样本外研究编排兼容，需将规则策略在该入口明确标注暂不可用，不得静默把自定义规则错误映射到 MA/RSI/突破。避免提前扩展优化器或多币种。

## 必须测试

- 每个规则条件/AND/OR/双侧规则/warm-up/同根冲突/无动作/末根无成交、非法数字、越界规则、空规则、版本不匹配。
- **历史前缀因果测试**：追加未来数据后，所有已有信号、成交、权益快照不变；独立数值参考测试指标/信号。
- 相同数据 hash + 相同规则版本与参数 + 相同成本假设，运行结果/hash完全一致；规则编辑后成为新版本，旧结果不变；保存、刷新重开、JSON导入导出可复现。
- 老三策略 / 2A-5A 的所有冻结参考及回归均保持；禁止删除断言、跳过、放宽阈值以换 CI 绿色。
- 50,000 根数据实际 Worker 性能与交互响应、双浏览器 E2E（Chrome/Edge）及窄屏，记录硬件和时长。
