# Phase 5C-A 实现复核

## 金额、时钟与版本

组合编排只调用冻结的 runBacktest 与 calculateStatistics。资产间只共享经过验证的 UTC 时钟。报价币由组合声明并同每个数据集符号校验；子引擎既有 manifest 保留原始假设字符串，组合以一单位引擎记账单位对应一单位声明报价币，全部行情与现金使用该报价，未引入换汇。

每个账户只对所选切片产生信号，最后一根收盘后的待执行信号不越界。组合每根收盘核对现金与市值之和、各账户权益之和。期末资金占比包括该账户现金，持仓占比只包含持仓市值。各币种净盈亏除以组合初始本金给出收益贡献，手续费占比的分母为组合总手续费，分母为零时显示原因。回撤比较使用整数交叉乘法，以组合初始本金为峰值起点。相关性使用原资产收盘价；简单收益以 96 位十进制计算，Pearson 系数保留 12 位，少于两项观测和零方差有独立原因。

两资产独立 Decimal 样本有 11 笔成交，期末权益 `945.781329616484887501`，组合最大回撤比例 `0.282142891394`，资产相关系数 `-0.154158509`。五资产、尾差、限额、前缀、成交保护等用例与三个 Windows 完整历史实验单独核对。[Python 参考](../tests/reference/portfolio_reference.py) · [数值回归](../tests/unit/portfolio-numerics.test.ts)

## 数据、存储与容量

完整源快照合计上限 10,000 根，最多五次子运行。即使只选小交集也要保存所有来源，区间外行情计入上限。对齐仅允许完整固定周期的连续快照。报告记录 UTC 毫秒开盘闭区间、末根收盘截止时间、数据及规则来源、各账户账本和统计以及组合结果。

Worker 顺序运行。实验的 payloadHash 覆盖输入和结果；记录 Hash 同时保护 ID、名称、时间、格式和版本。导入和重开都使用完整快照重算。独立 IndexedDB 的摘要及正文同事务新增，ID 冲突时保留原件。旧实验、规则、数据集与回放库沿用各自结构。

导入文件最多 32 MiB，生成的报告还须通过规范 ASCII 字节预算。工作内存准入预算为 256 MiB，其中 128 MiB 预留给文件、字节缓冲和解码，另 128 MiB 计入两份对象树。浏览器另有 Worker、渲染器、JS 引擎及原生内存开销。实测方法使用生产 Worker 客户端，分别运行 2×5,000 和 5×2,000 根，导出完整 JSON，再通过实际文件入口恢复，比对 Hash、曲线长度和成交。主线程 20 ms 采样，Linux 另按 CDP 进程清单约每 100 ms 采样 RSS 之和，其中共享页可能重复计入。每次 CI 打印对应平台的实测值。[测量脚本](../scripts/profile-portfolio.mjs)

## Linux Chromium 边界实测

Linux 6.18.57、Xeon Platinum 8573C、Node 24.19.0、Chromium 154.0.8037.57，三次各启新浏览器，依次运行两种组合。耗时取中位数，内存及主线程间隔取三轮采样最大值。每轮导入恢复均重算得到原组合 Hash。

| 数据与成交             | 运行 ms | 导出 ms | 恢复 ms | JSON 字节 | 主线程 JS 堆 MiB | 浏览器进程 RSS 合计 MiB | 最大定时器间隔 ms |
| ---------------------- | ------: | ------: | ------: | --------: | ---------------: | ----------------------: | ----------------: |
| 2 × 5,000 根，1,050 笔 |     719 |    1147 |    1046 | 8,119,426 |             27.3 |                   594.5 |               181 |
| 5 × 2,000 根，2,487 笔 |     977 |    1552 |    1270 | 8,901,572 |             26.3 |                   616.7 |               226 |

计时包含 Worker 启动、传输和返回。导出也进行完整校验与重算。表中不含 CSV 准备、IndexedDB 存盘或 UI 绘图；实际页面和解压包流程由 E2E 单独验收。RSS 是采样值，受主机、浏览器本身及共享内存影响。

## 已知边界

交易对来自数据集声明，来源真实性仍由使用者核实。仅支持同报价现货虚拟资金，各账户无透支或跨资产转移。买入持有任一分项不能成交则整体基准为 NA。按收盘估值的回撤不覆盖根内价格路径。浏览器存储配额依设备与配置而异。图表转换为 Number 绘制；JSON、表格和 CSV 保留定点账本。用户实机签署单列。[Windows 验收清单](phase-5c-acceptance.md)
