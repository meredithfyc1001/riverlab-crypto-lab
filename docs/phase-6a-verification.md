# Phase 6A · Windows 验证原型与验收报告

此候选面向 Windows 11 x64。它将研究工作台和十个生产 Worker 入口打入 Tauri 2，使用专用 WebView2 profile。前端工具链在构建机上使用 Node 24，运行桌面程序只需要兼容的 WebView2。工作台现有页面在专用 profile 里验证原功能，单独的 Rust IPC 验证 SQLite；完整业务存储适配及用户数据导入处于 6B 设计阶段。[架构决策及九库映射](phase-6a-architecture.md)

## 可重现的技术验证

Windows 上通过安装后的同一 EXE 运行工作台。测试进程使用新的专用 profile；内置验收按真实页面、Worker、SQLite 和下载入口操作，将就绪、首个 Worker、完整结果或错误写成受限回执。外部驱动独立读取下载文件、比对 SHA，并从 Windows 采样进程树。系统 Edge 使用独立空配置和 Playwright 操作同一前端。正常交互启动不注册自动验收，不要求开启远程调试端口。
