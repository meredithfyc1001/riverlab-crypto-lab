# 1.0.0-rc.1 Windows 本地验收清单

记录本次使用的完整 head SHA、内层 ZIP 的 SHA-256、浏览器/Node 版本、每项实际观察和状态。请仅记录可共享的环境信息，现场含主机名、私人目录或个人数据的证据留在本机。先用新的浏览器配置检查空库，再用已有测试配置验证重开。不要清除日常使用的浏览器数据。

| 操作           | 预期与核对方法                                                                                                                                                                                                                   |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 核验并启动     | 从 Draft PR 下载当前 head 制品，按摘要核对内层 ZIP，完整解压到中文空格路径。核对 build-info 的 version=1.0.0-rc.1、phase=V1.0 RC、SHA 及 dirty=false，检查 SHA256SUMS。预装 Node.js 24，双击 BAT，观察 READY 和 127.0.0.1:4173。 |
| 首次使用       | 打开数据、行情、回测、策略和风险页，检查入口可达，空库未自动写入。选内置历史样本，再区分人工合成入口。确认 24/24、1小时、UTC、质量警告，明确保存。                                                                               |
| 导航和持久化   | 键盘访问八页及控件，查看深浅主题、窄屏和长中文名称。关闭后重开同浏览器/地址检查已保存数据和实验，观察未保存内容的提示。                                                                                                          |
| 三个历史实验   | 将 MA 2/4、自定义 V1、V2 原始 JSON 导入无数据和规则的新配置。在预览核对三行最终权益、费用、runHash 后才确认保存。刷新后重开并再导出。数值见[实机基准](v1-rc-windows-baseline.md)。                                               |
| 拒绝损坏与冲突 | 在原件的副本上修改版本/Hash/结果，确认拒绝且列表不变。重新导入已保存的同 ID 正确文件，确认已有记录未被覆盖。取消预览后刷新，检查列表。                                                                                           |
| 原有功能       | 图表、研究比较、规则版本、逐根回放、风险模拟和各类导出分别检查。回放需要原数据身份，其他对象的备份要求见[说明](rc-backup.md)。                                                                                                   |
| 取消与退出     | 回测计算期间取消，再次运行。完成后在 BAT 前台按 Enter 退出，检查 STOPPED、进程正常结束和 4173 端口释放。                                                                                                                         |

2026-11-25 的六项 PASS 对应 0.5.1-test。当前 RC 用户实机状态待用户逐项记录。物理断网及断网后刷新、读取、回测、恢复、导出和图表/Worker 由用户暂缓，维持 **NOT TESTED**。真实磁盘耗尽、受管策略等也只在实际执行后更新。平台 CI 与 Windows ZIP 自动测试分别记录在 Draft PR。
