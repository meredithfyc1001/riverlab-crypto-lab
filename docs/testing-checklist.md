## 自动化分工

- Vitest 单元：hash 的有效/缺失/异常输入；合成来源、UTC 毫秒和 OHLCV 约束。
- Vitest 页面集成：中文入口、风险提示、样例标识、键盘主题、深链接占位、hash 变更。
- Playwright：生产包八入口、刷新/后退、主题、仅本机资源、无错误；390px 导航/溢出。
- CI：Ubuntu Chromium、Windows Chrome/Edge 执行 npm run check，保留浏览器报告。
