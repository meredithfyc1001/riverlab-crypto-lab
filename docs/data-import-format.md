# 导入约束（Phase 1 待实施）

当前没有 CSV/ZIP 导入、映射、存储和质量校验器，只有明确标注的人工合成只读样例。

后续首版手工导入真实 OHLCV CSV，定义来源/许可、币种、周期、时间单位、原文件标识/哈希和错误行报告。严格检查递增时间、重复、缺口、负数、非有限值、OHLC 和周期一致性，不默默补价格或丢行。

内部统一 UTC 毫秒。输入检测或明确指定单位；Binance Public Data 现货归档自 2025-01-01 起用微秒，不能统一当毫秒。用真实毫秒、真实微秒、歧义和错误样本分别测试，UTC 与显示时区分离。

大文件用流式或 Worker；本地存储检测配额、拒写、隐私模式，明确文件导出回退。以上只记录原规划约束，不代表已实现。
