# Phase 2B 实现后自查

按输入字段、每根事件、精度、订单冲突和输出身份逐项追踪。此为代码自查，未使用其他代理，不能替代用户Windows验收。命令和失败证据见 [progress](../progress.md)。

| 重点          | 结论与证据                                                                                                                                                                                                                                                                              |
| ------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 无未来数据    | 策略闭包只接收冻结的当前已完成Candle；没有dataset/未来数组/任意用户回调。MA滚动和、RSI状态和突破单调队列只包含过去；突破先比较再入队。18组独立固定参考逐个前缀对比，三策略再经完整引擎+保护执行逐个前缀验证成交/信号/快照。                                                             |
| 信号定义      | MA首次可用只建立基线，跨越等号后发信号；RSI明确阈值包含等号和Number边界；突破严格比较此前high/low。正式策略all、long/flat，不加仓、不做空。原固定信号独立入口保留。                                                                                                                     |
| 参数与数据    | 规范参数快照和冻结策略配置；未知键/类型/NaN/越界拒绝。dataset-v1重新校验，缺口/未完成/精度越界/空数据均阻断；不补价/排序/截断。                                                                                                                                                         |
| 时序与保护    | 已有仓开盘保护→否则上一根信号→新保护激活检查→根内触发→收盘估值/信号。开盘风控尝试后取消待执行订单，即使拒单也不重复处理；原仓/新仓双触发均stop-first。部分卖出的余仓保持entry。                                                                                                         |
| 激活边界修复  | 自查发现极大买入滑点可使新仓stop高于open，原稿错误地在根内按较优stop报价退出。先新增测试复现44通过/1失败，再改为新保护立即检查已知open，按open退出。100开盘、9999bps买滑点、2单位、10%止损：entry199.99、stop179.991、退出参考100、最终现金800.02。失败原日志归档，未放宽阈值或删断言。 |
| 未知路径/时间 | 根内触发timestamp/generated/resolved=null，附开闭区间；双触发明确ambiguous-stop-first，不根据收盘方向推断。开盘（含新保护立即触发）有精确已知时间；同根仅允许开盘信号和一次保护退出。                                                                                                   |
| 跳空/成本     | 止损跳空按较差open；止盈跳空保守放弃价格改善、按take。保护为触发市价，继续扣卖滑点/费用，可低于止盈阈值。executeAtReference只接收参考报价，无HLC/量；全量数据质量/触发逻辑与执行分离。                                                                                                  |
| 定点/资金     | 18位BigInt资金/MA比较/突破比较；entry基于实际滑点价、不含费用，stop floor/take ceil。极小stop归零阻断；派生价用readUnits，不错误套用原始输入上限。两笔同根、部分卖后保护、极小费量和拒单均独立对账。                                                                                    |
| 审计范围      | assertLedger独立重算现金/持仓/费用/权益/累计额和事件顺序；保护整仓数量及阶段/时间空值、唯一ID额外检查。它不认证原OHLC或外部触发证据真伪。保护快照按选定参考报价估值，收盘仍按实际close。                                                                                                |
| 可复现        | 新算法版本，策略类型/版本/参数、风险参数、实际信号绑定hash；每次新状态，无时钟/随机/网络。相同输入JSON完全一致；未来全量hash可变，既有历史结果不变。                                                                                                                                    |
| 独立参考      | Python Decimal 100位与朴素历史窗口独立生成18组策略固定序列、5组保护资金案例；未调用TS生成期望。JSON由Vitest核对；Python --check额外运行，无新增应用或CI运行依赖。                                                                                                                       |
| 依赖方向      | 抽取原18位算术为core/math叶模块，保留backtests/decimal兼容导出。strategy/risk不反向依赖backtests，核心无DOM严格编译，未引入网络或存储。                                                                                                                                                 |
| 回归与范围    | 全部原159项Vitest及17项E2E保留；原测试断言/阈值/浏览器配置/CI矩阵均不改，fixture仅收窄原固定输入返回类型以兼容新增联合类型。无UI组件变更、无新增依赖。                                                                                                                                  |

剩余限制：RSI仍为IEEE754指标，极接近阈值时存在舍入边界；原Number价格丢失精度无法恢复；无限流动性/无冲击/零量可成交仍是模拟假设。同步内核无Worker/取消或浏览器大数据性能承诺；无收益面板、公平基准、统计NA、实验保存或参数优化，完整M2待2C。1B/2A/2B用户Windows未测试。
