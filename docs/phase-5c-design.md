# Phase 5C-A 多币种组合回测设计

基线是 PR #11 实际合并提交 `c8ded9304785a06c713f5a830caf292bacbc918f`。原引擎的成交顺序、舍入、版本与实验 Hash 是冻结的回归契约。

## 资金与成交

一次选择 2～5 个同报价、同周期的不同现货交易对，每个子账户持有自己的现金及单一资产。权重正数且以十进制精确合计 100%。本金乘权重后向下取至 18 位最小单位，按乘积余数从大到小逐单位补发，相同余数按规范交易对字典序分配。每个正权重须分得正本金。所有子账户空仓开始，独立应用内置策略或已保存规则修订、费用、滑点与保护。现金与资产始终留在原账户。

## 行情与组合统计

完整快照须通过数据质量检查。预览以 UTC 毫秒的开盘时间表示闭区间，显示交集、选定边界及逐资产首尾截取；每个选定时间都必须是实际行情且逐根匹配，确认后才能运行。最后收盘须已完成。策略首根从零状态启动。按收盘逐点汇总现金、市值、总权益，并与各账本相核对。初始锚点参与峰值回撤计算。初始配置权重、子账户实际权益占比、资产持仓市值占比分列。

组合买入持有按相同分配在首开盘执行，使用同买滑点、手续费、数量精度和最小名义额，末收盘估值。被拒绝时说明原因。资产 Pearson 相关性取同步的相邻收盘简单收益，至少两个收益观测；某一序列无方差时展示原因。

## 复现与边界

独立组合报告含原始完整数据、区间与确认状态、可执行策略与规则版本记录、成本、风控、子账户运行和组合结果。版本及规范 SHA-256 覆盖配置和结果。导入在 Worker 先做体积、结构、版本及 Hash 校验，再独立重算后供确认保存，摘要与正文同事务。每次 Worker 顺序运行各账户，完整原始行情合计最多 10,000 根，含截去的行情，紧凑 UTF-8 报告最多 32 MiB。测量边界运行与恢复的耗时、内存和报告体积，具体资源预算与口径在复核中记录。

## 风险与验收

报价标识由数据集符号与组合声明显式验证。尾差、浮点金额误差、跨区间预热、错位相关性、报告膨胀和事务部分写入分别用定点守恒、前缀、独立数值参考、边界压力和存储失败测试覆盖。旧单币种 Windows 三份原件、473/50 基线及独立参考全部保留。三平台质量检查后从最终 head 制作 ZIP，由 Windows Chrome 与 Edge 解压验包。用户实机及物理断网单独登记。
