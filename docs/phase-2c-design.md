## 指标口径（statistics-v1）

- 现金、数量、费用、市值与权益来自原账本；每根收盘权益=cash+floor(quantity*close/1e18)，不扣假想末尾清仓费；曲线另含首根开盘前初始本金锚点。总净盈亏=末权益−初始本金；收益率=净盈亏/本金，本金0为NA。
- 成本基础采用含买手续费的加权账面成本。部分卖按卖出量/卖前持仓向下分配18位成本，最后平仓分配全部余数；已实现=卖名义额−卖手续费−分配成本。浮动=末市值−剩余成本；两者之和严格等于总净盈亏。滑点已进入成交名义额，不重复扣。资金无Number累加。
- 完成交易为从空仓到再次空仓的完整持仓周期。部分退出计已实现但未完成整个周期不进入胜负。胜率=净盈利周期/完成周期（平手计分母）；利润因子=完成周期净盈利总和/净亏损绝对总和。无完成周期NA；无净亏损NA（明确原因，不伪造无穷/100%）。
- 回撤=峰值权益−当前权益；比例=回撤/峰值，峰值含初始锚点，0峰值NA。最大回撤以未舍入分数比较；最长回撤持续时间从最后一次达到峰值到恢复到不低于峰值的收盘，未恢复计算至末收盘；无回撤0ms。离散收盘观测不代表根内风险。
- 暴露时间为持仓覆盖K线区间上界：根开盘持有或该根有买入即记整根，卖出发生于开盘且无重新买入则该根不计；根内退出计整根。因根内时间未知，不声称精确连续暴露。比例=暴露ms/首开至末收盘ms。
- 买入持有基准：同区间/本金/费用/买滑点/数量精度/最小名义额，首根开盘按被动预先承诺买入，持有至末收盘市值计量，不强制平仓、不扣卖成本、无止盈止损。拒单明确NA与原因，不把未买到视为0%基准。
- 比例用BigInt除法向零截断到12位小数，显示百分数乘100后精确保留最多10位；金额输出18位规范字符串、不改账本值。CAGR仅跨度>=365天、收盘点>=252、初始/末权益均>0时计算：(末/初)^(365天/跨度)−1；此无量纲幂用Number并记录近似，使用toFixed(12)按JavaScript近似舍入（不采用BigInt比例的截断规则），非有限或绝对值>=1e21时NA。其他情况NA与具体原因。零收益可在有足够有效样本且无变动时返回0，不能用0替代缺失输入。

## 实验、存储与恢复

实验记录含dataset-v1完整快照（不含原CSV）、数据集ID/文件hash、manifest全部版本/假设、完整结果、统计版本/定义及统计、外部运行时间。结果计算不读时间/随机；实验外层id/创建时间由app提供。报告校验hash绑定全部payload，仅检测损坏不认证来源。重新打开在Worker核对hash、版本并重新计算结果/统计逐字节比对；损坏拒绝，不修复。保存为新记录，删除实验不删除数据集；原数据集删除后内嵌快照仍可重开结果和复现。JSON报告含完整复现数据；CSV为逐笔成交，保留unknown根内时间/区间、触发假设、费用与前后余额。均附“仅供学习研究，历史表现不代表未来表现”。CSV引号转义并防止文本公式注入。

复用IndexedDB事务适配器，实验采用独立数据库避免升级阻塞/改写原数据。事务complete才成功；配额、策略拒绝、abort、损坏明确失败，保留内存结果可导出。摘要只加载小元信息。当前配置/未保存结果只在网页会话保留，刷新重置；已保存列表刷新可见，需明确打开，不静默启动旧实验。不保证浏览器永久保存，JSON需用户确认下载并另行备份。

## Windows ZIP与验收

仅dist、Node内置模块server、BAT、说明、版本/head SHA、逐文件SHA256。Node24运行时用户预装。服务仅127.0.0.1，端口固定4173（已占用即明确失败，保持同源存储）；可显式指定其他端口但提醒来源隔离。无POST/上传、遥测、外部依赖。严格decode/段检查/realpath根内检查、仅dist白名单文件，拒绝穿越、反斜杠、symlink外逸与未知扩展；默认index，其余404。前台服务、Enter/q或Ctrl+C退出并关闭连接；无后台服务。启动打开浏览器失败仍显示可复制URL。BAT引用自身绝对路径，支持中文空格路径并保留失败窗口。
