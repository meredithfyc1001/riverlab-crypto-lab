# Phase 5C-A Windows 实机验收清单

待用户在 Windows 本机按最终 Draft PR 下载的制品执行。每个浏览器独立记录版本、PASS、FAIL、BLOCKED 或 NOT TESTED，以及实际观察。历史 RC 的[实机记录](phase-5c-rc-baseline.md)另存。

| 项目       | 操作与预期                                                                                                                                                                    |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 验包与启动 | 核对内层 ZIP 的 SHA-256、包内清单、build-info 完整提交和测试版号。解压中文空格目录，从 BAT 启动，确认回环服务及浏览器访问。                                                   |
| 选择来源   | 在数据中心保存两份有共同区间的不同交易对，复测五个交易对。打开回测中心的组合入口，选择不同内置策略及已保存规则修订，设置不同费用和滑点。                                      |
| 权重与时间 | 试验少于和超过 100%、重复交易对、不同报价或周期、有缺口、同周期错位、未来末根。无有效配置时不能完成运行。对不同首尾但严格对齐的行情查看逐币截去范围，缩短选定范围并重新确认。 |
| 资金与统计 | 分别对应初始权重、实际权益权重和持仓权重。核对组合终值与各子账户权益之和、总手续费与逐笔费用之和，检查组合/子曲线、买入持有、收益回撤与相关性 NA 原因。                       |
| 保存与复现 | 保存、刷新重开、完整复现、导出 JSON 和 CSV。在空白浏览器配置中用 JSON 单独恢复，核对组合 Hash、子账户成交与完整曲线，确认保存，再删除选定实验。                               |
| 拒绝与保留 | 分别修改报告版本、输入和结果，确认拒绝，原库中的实验还能重开。检查浏览器拒绝存储或配额不足时提示，仍可从内存结果导出备份。                                                    |
| 历史回归   | 在原实验入口重开 MA 2/4 和规则 V1、V2，核对[原始数值锚点](v1-rc-windows-baseline.md)。                                                                                        |
| 退出与断网 | 正常停止 BAT 并检查端口释放。物理断网检查待用户实际执行；如暂缓，记录 NOT TESTED。                                                                                            |
