# 如何备份和恢复研究记录

浏览器 IndexedDB 按配置和来源隔离。同一台电脑换浏览器、用户配置、地址或端口，打开的库都可能不同。清理站点数据、隐私模式、磁盘配额和浏览器策略都可能影响持久化。请在清理或换机前下载所需的 JSON 并核对文件。成交、研究、回放和风险 CSV 用于阅读或二次分析，恢复需要对应的 JSON。

| 对象     | JSON 包含的内容                                                               | 恢复条件与保存行为                                                                                                                                    |
| -------- | ----------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| 数据集   | 已检查 K 线、时间/周期、来源、原文件摘要、质量报告和警告                      | 在数据中心预览来源和范围，确认后恢复为新副本，取得新的 ID。上限 20 MiB、50,000 根；原 CSV 需要另外保管。                                              |
| 规则策略 | 一个不可变的家族版本、双侧条件、版本和校验摘要                                | 在策略中心导入，核对后保存。同一家族和修订号冲突时拒绝写入。文件上限 128 KiB，策略库最多 100 个版本。                                                 |
| 回测实验 | 完整数据快照、策略及成本、保护参数、逐笔成交、逐点权益、统计、算法版本和 Hash | 在实验中心选择文件。校验并重算成功后先预览，确认才写入。按实验 ID 防止覆盖；同名的不同 ID 可以并存。全新浏览器无需原数据集或原策略库。                |
| 策略研究 | 输入数据快照、候选、窗口、成本、统计结果、版本及 Hash                         | 在策略中心重新打开研究 JSON（25 MiB），重算后只在内存中展示；刷新前请保管文件。                                                                       |
| 历史回放 | 数据集 ID 和 Hash、配置、游标、已揭示的操作与日记及校验值                     | 在历史回放恢复（10 MiB），原数据集须以相同 ID 和 Hash 存在，恢复后保持暂停。普通数据集备份导入会产生新 ID，因此这两份 JSON 不能保证换机后接续旧回放。 |
| 风险报告 | 源实验复现输入、模型参数和种子、模拟输出及校验值                              | 在风险中心导入（25 MiB），Worker 重建源实验并重算，预览后可保存。原数据集和原实验可以不在当前配置中。                                                 |

## 从实验文件恢复

1. 在原浏览器打开回测结果，导出完整实验 JSON，确认文件已实际下载。保管原文件和对应算法版本的本地包。
2. 在新浏览器配置启动同一版或兼容的测试包，进入“实验中心”，选择实验 JSON。导入上限 256 MiB；大文件需要足够内存，校验期间可以取消。
3. 等候校验和重算，核对预览里的实验名称、币种、策略、最终权益及运行摘要。SHA-256 用于检测内容变化；它不能证明数据的市场来源或签署者。
4. 确认后保存，再刷新并打开该实验。遇到重复 ID，保留库内原记录；要检查另一个同 ID 文件可在独立浏览器配置中预览。若是格式、版本、数据、校验或重算错误，保留原文件及错误提示。配额、权限或事务错误时先核对列表，保管备份再重试。

各入口按对象分别工作。实验内嵌策略和行情用于复现；若需在数据中心或策略库中单独编辑、复用，还需分别导出和导入相应对象。
