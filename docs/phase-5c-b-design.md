# Phase 5C-B 共享现金与定期调仓设计

基线 `fd4de40c32623eab3eb16555fc0df723d6e22357`，测试版 `1.1.0-test.2`。历史数据按既有组合口径在共同 UTC 区间冷启动，原始快照总计最多 10,000 根，完整报告最多 32 MiB。固定子账户沿用原算法和报告。以下约定用于两个新的虚拟现货模式。

## 时钟与决策

每根先收集全部开盘引用价。策略模式先处理既有仓位的开盘保护，再执行上一收盘的普通卖单；再平衡模式按开盘初始权益和目标市值先减仓。开盘卖出的净款可用于同根开盘买入，这是全额模拟成交且即刻结算的假设。卖出结束后，用实际现金及按同一组开盘价估值的剩余持仓，重新计算开盘权益。各资产同时申请，全部批准后才执行买入。随后处理根内保护，双触发先止损，记录失败原因。已保护退出的资产同根禁止回购。根内卖款只能留待后续开盘。最后按已完成的收盘价估值并交付本资产策略。末根决策可记录，无后继开盘不能成交。

策略模式每个交易对限一笔多头持仓，买入只接受空仓信号，卖出平掉全部。每资产仅见其已完成 K 线，各自使用内置策略或已校验的规则修订。再平衡模式在所选区间第 N、2N、3N 根收盘安排调仓，下一根开盘执行；只提交调仓意图，开盘才按已知价格确定数量，允许部分买卖。该模式的配置独立于策略与保护，不执行两套控制。

## 预算、舍入和账本

权重以百分数的 18 位定点整数计。策略比例之和至多 100%，差额为目标现金比例；再平衡各资产和显式现金目标合计精确等于 100%。减仓量按开盘超配市值除以开盘价后向下取数量步长。减仓后申请额为目标市值与已持市值的正差，策略模式只对合格买入信号申请。目标现金金额按统一开盘权益计，买入容量为共享现金减储备，下界为零。若申请总额超容量，各批准额向下取整到最小金额单位，再按规范交易对 ASCII 顺序分派剩余单位。单次分配，不回收拒单或取整余款做第二轮买入。

买入用原单资产成交函数及批准预算，数量向下，买入价格与名义额向上、卖出向下、费用向上取整。成交以共享现金和实际资产数量逐笔入账，拒单不改余额；资产净贡献为累计卖出净收入减累计买入总支出加剩余市值；费用已包含。每根要求各贡献之和等于权益减本金。收盘权益等于现金加各资产市值；回撤比较用完整曲线和本金锚点。展示目标与实际资产和现金权重、持仓暴露、调仓前后偏差及未成交原因。不单列部分平仓的已实现盈亏。

固定配置基准在共同区间首开盘依初始目标买入一次，保留目标现金与取整余款，使用同一费率、滑点、数量步长和最小额，期末按收盘估值。基准拒单须披露。策略与再平衡账本保留申请、批准、实际支出、费用和前后余额。

## 报告与验收

新报告按独立格式及算法标识分派。保存完整原始数据、区间、成本与参数、规则版本、时序决策、事件和组合结果；在 Worker 中对版本、结构、SHA-256 和完整重算做检查，导入失败或重复 ID 保留原库。页面可取消计算，独立配置恢复后对账。旧报告按原验证器处理。
