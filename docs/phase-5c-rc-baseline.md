## 现场观察

- 首次刷新重开已保存的 50,000 根实验，5 秒时仍未完成，**8.498 秒**时全部曲线就绪。重启同一 Chrome 配置后再开，3,450.3 ms 时显示校验成功，4,065.6 ms 时全点就绪。原 5 秒成功提示门槛适用于运行回测。完整导出为 71,011,092 字节。
