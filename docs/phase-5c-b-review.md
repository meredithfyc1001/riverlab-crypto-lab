# Phase 5C-B 实现复核

## 账本与可复现性

共享账本按统一开盘价执行。每次成交独立校验引用价与滑点、数量步长、名义额、手续费、可支付预算、共享现金和累计持仓。资产贡献逐根由累计净卖出、含费买入及持仓市值计算，合计须等于组合权益减初始本金。新报告标识为 `riverlab-shared-pool-experiment` v2，执行时钟 `shared-spot-clock-v1`。策略和调仓分别采用 `shared-spot-strategy-v1`、`shared-spot-rebalance-v1`。不同输入排列按规范交易对排序，记录的行情与策略版本随同排序。

再平衡只保存定期收盘决策；下一根开盘才计算数量。偏差为实际百分比减目标百分比，单位为百分点。因费用及数量限制，按同一开盘价格计算的成交后现金权重仍可能偏离目标。定点金额在 JSON、CSV 与明细表保留全部精度，图表用近似值绘制。买入持有以各资产的首开盘成本和期末收盘估值计算；无法买入的一项保留现金并报告原因。[资金、事件及舍入规则](phase-5c-b-design.md)

## 独立整数对账

Python 参考独立实现信号、保护、18 位舍入、资金分配、部分卖出、基准和组合估值。10 组人工路径共 33 笔成交。TypeScript 与固定参考逐笔和逐点对比，另对输入倒序、每个历史前缀、切片后的冷启动和可重复运行作校验。代表性结果如下，回撤及基准收益为小数比例。[参考程序](../tests/reference/shared_pool_reference.py) · [独立数值测试](../tests/unit/shared-pool-numerics.test.ts)

首次对账捕获了一个额外的最小单位手续费。正目标市值取整成零时，原开发实现走了全平路径。现统一以超配市值除以开盘价、再向下取数量步长；若名义额不足，账本保留原仓位与拒单。独立参考值保留。另一项前端回归覆盖缩短选区后仍需确认全部源行情已收盘；计算时只向策略交付选区内的收盘数据。

复核还重现了两项边界。开盘买价为一个最小单位、止损为 1 bps 时，早期实现会在入账后计算保护价并抛错。现先验证保护价，拒单记为 `stop-price-underflow`，保留共享现金与整笔预算。另一案例把报告资产倒序并重签两层 Hash；新格式恢复入口现显式检查规范顺序，避免恢复出的输入与重新创建的身份不一致。
