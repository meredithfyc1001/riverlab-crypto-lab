# RiverLab Crypto Lab · Phase 6B Windows 验收包

本包包含独立 EXE、当前用户 NSIS 安装器、构建身份与两份 EXE 的 SHA-256。安装和直接启动均使用同一用户级研究目录。请在专用 Windows 11 x64 普通账户或干净虚拟机中使用合成数据，准备已安装的 Microsoft Edge WebView2 Evergreen Runtime。

| 项目            | 步骤与判据                                                                                                                                                                                                                                                                                                                                                  | 实机结果               |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------- |
| 构建身份        | 记录 `build-info.json` 的源提交、运行号与尝试编号。对内层 ZIP 运行 `Get-FileHash -Algorithm SHA256 -LiteralPath '内层 ZIP 路径'`，与随附的 `.zip.sha256` 对照。在含中文和空格的解压目录运行 `Get-FileHash -Algorithm SHA256 -LiteralPath '.\RiverLab-6B-x64-setup.exe','.\riverlab-desktop.exe'`，逐项核对 `SHA256SUMS.txt`。记录 Windows / WebView2 版本。 | 待填写                 |
| 安装与首次运行  | 当前用户安装并启动。打开工作台的本地服务信息，记录服务、IPC、schema 版本、数据路径和可用空间。确认数据库、日志、备份在用户目录，安装目录只有程序文件。                                                                                                                                                                                                      | 待填写                 |
| 并发与退出      | 保存一份已检查合成数据集，尝试从另一入口重复启动。核对第二实例不能同时写入，原窗口仍可读写。正常关闭，随后启动独立 EXE，用原 ID 打开数据集。                                                                                                                                                                                                                | 待填写                 |
| 事务与完整性    | 创建回放、前进一根并显式保存；退出、重开并恢复同一游标。执行完整性检查，记录结果。用测试账户执行一次手动备份，记录固定备份目录中的文件。                                                                                                                                                                                                                    | 待填写                 |
| 异常退出与权限  | 使用专用临时账户，在保存合成记录后结束应用进程。重启后做完整性检查并核对已提交数据。在独立测试目录按拒写、恢复权限、重试顺序记录行为。空间不足用测试卷或配额模拟，记录错误提示及原有记录内容。                                                                                                                                                              | 待填写                 |
| 升级模拟        | 记录合成数据 ID、导出字节与 SHA，关闭所有桌面窗口，覆盖安装同一候选包，再次打开并核对数据路径与原内容。注明本次覆盖安装的两个版本。                                                                                                                                                                                                                         | 待填写                 |
| 研究结果对照    | 使用内置桌面技术验证的 50,000 根样本，记录 100,000 次求值、2,082 笔已平仓交易、单通道和双候选结果。冻结完整结果 SHA-256 为 `e3fb4410dc0bac12ca6dc1d108d4a6ae2f56107a47fc20bbda789469cbaf5d6b`。浏览器对照请使用专用空 Chrome、Edge 配置。                                                                                                                   | 待填写                 |
| Phase 6A 第三轮 | 分别核对安装版、独立 EXE、Chrome、Edge 的深浅主题四张研究路径卡片和各状态描边、焦点对比度。测试同名文件保留、拒写及恢复重试，实际比对磁盘大小与 SHA，记录 32/33 共享冲突能否复现。                                                                                                                                                                          | NOT TESTED，待用户执行 |

逐项记录 PASS / FAIL / BLOCKED / NOT TESTED，保留实际文件摘要及错误原文。仓库中的 Phase 6A 验证规程列有历史实机证据和第三轮各项判据。运行清单时使用专用目录，避免改动日常浏览器配置。
